El Lenguaje ICod

Código que habla todos los idiomas a la vez.

ICod es el pegamento ultrarrápido entre lenguajes. Mezcla Python para IA y data science, JavaScript para lógica web y Rust para velocidad crítica — todo en un solo flujo y sin fricción.

Lo mejor: cuando un desarrollador escribe un nodo en ICod con anotaciones simples, NodCoT+ autogenera el formulario visual para que cualquier persona sin conocimientos técnicos pueda usarlo inmediatamente.

harvest_and_build.icod
// ICod — extrae colores y construye un sitio flow buildSiteFromBrand(url: String) { // Extrae paleta con K-Means en espacio LAB let palette = @harvest(url) |> kmeans({ clusters: 6, space: "LAB" }) |> wcagFilter("AA") |> toDesignTokens() // Genera sitio con IA usando los tokens let site = @ai.generate({ model: "gemini", tokens: palette, prompt: "landing moderna y rápida" }) // Emite al Live Browser en tiempo real emit @preview(site) emit @deploy(site, target: "web") }

¿Cómo llegamos ahí?

Cada fase trae algo nuevo y usable. Construimos en público y la comunidad da forma al producto.

✓
Fase 0 · Completada
Repositorio & Landing Page
Repositorio privado configurado en GitHub. Landing page pública activa con lista de espera y panel de administración.
1
Fase 1 · En progreso
Canvas Reactivo & Motor de Grafos
Canvas infinito con React + TypeScript. Motor de ejecución DAG reactivo. Modo Fácil (formularios visuales) y Modo Dev (código) en el mismo nodo.
2
Fase 2
Lenguaje ICod v0.1 & Auto-UI
Tokenizador, parser y bytecode comprimido. Bridge de ejecución JS/Python. Sistema de anotaciones que autogenera interfaces visuales.
3
Fase 3
Nodos Inteligentes & IA
Extractor de colores (K-Means + WCAG). Conectores nativos para Gemini, GPT y Ollama. Nodos de automatización web y documentos.
4
Fase 4
Live Browser & Terminal
Preview en tiempo real vía WebSockets. Terminal embebida con soporte PTY. Inspección de estado nodo por nodo.
5
Fase 5
Beta Pública & Marketplace
Acceso a los primeros beta testers de la lista de espera. Lanzamiento del marketplace con nodos gratuitos y de pago. Sistema de paquetes .nco.
